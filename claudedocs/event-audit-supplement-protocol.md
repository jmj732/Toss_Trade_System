# 실적 이벤트 데이터 감사 보완 기준

작성일: 2026-11-24
성격: 기존 `event-audit-protocol.md`의 사후 보완 감사. 독립 검증이나 새 가설 사전등록이 아니다.

## 범위

- SEC `acceptanceDateTime`과 실제 수집기가 처음 응답을 본 `observed_at`을 분리한다.
- 실행 가능 시각은 `t_ready = max(acceptanceDateTime, observed_at)`로 정의한다.
- `observed_at`이 없으면 같은 날 시가를 인정하지 않고, 보수적으로 다음 거래일 시가만 가능하다고 기록한다.
- SEC·IR·EPS·추가 공시·비용·군집 수만 감사한다.
- 수익률·신호·백테스트·파라미터·주문은 금지한다.

## 보완 게이트

| 게이트 | 통과 기준 |
|---|---|
| S1 관측시각 | 사건별 SEC 접수시각과 수집기 `observed_at` 모두 존재. 없으면 당일 시가 불가 |
| S2 EPS | GAAP 희석 EPS와 전년 동기 GAAP 희석 EPS가 원문에서 확인되고, 후속 10-Q/10-K XBRL과 값·부호·기간이 일치 |
| S3 추가 공시 | Item 7.01/8.01/2.05를 번호가 아니라 실제 내용으로 분류. 가격 영향 가능 사건은 `CONFOUNDED` |
| S4 비용 | Toss 공식 수수료 출처, 계좌별 적용률, 기존 체결의 commission/tax/filled price/filled_at을 분리. 미확인 값은 추정치로 표시 |
| S5 검정력 | 기업·날짜·보유기간 군집을 반영한 유효 독립 사건 수가 계획상 최소 1,100건을 넘는지 평가. 군집 보정 전 raw 건수만으로 통과시키지 않음 |

## 시가 규칙

- `t_ready < 09:30 ET`: 해당 거래일 시가 가능성은 `observed_at`이 실제로 09:30 전임을 확인한 경우에만 인정.
- `09:30 ET <= t_ready < 16:00 ET`: 다음 거래일 시가.
- `t_ready >= 16:00 ET`: 다음 거래일 시가.
- `observed_at` 없음: 다음 거래일보다 빠른 체결을 인정하지 않음.
- 거래일·시가 행이 없거나 기업행사가 해결되지 않으면 `UNRESOLVED`.

## 판정

- S1–S5 전부 통과할 때만 전체 유니버스 확장을 제안할 수 있다.
- 하나라도 실패하면 전체 확장을 제안하지 않고, 실패 원인과 보완 요건만 보고한다.
- 이 기준은 이미 본 가격·SEC·IR 구간에 적용하는 데이터 감사이며, 독립 수익률 검증이 아니다.
