# Lead-Lag 연구 사전 등록 (LL-1)

등록일: 2026-11-23. 개별 종목 데이터 수집 **전**에 커밋한다. 커밋 시각이 사전 등록의 증거다.
이 문서 이후 가설·설정·판정 규칙을 바꾸면 새 등록(LL-2)으로 취급하고 시도 횟수 N에 누적한다.

## 0. 범위와 금지

- 연구 전용. 주문·승인 정책·위험 관리·운영 데이터는 변경하지 않는다. 주문 실행 금지.
- 기존 54개 설정(`strategies.py` 그리드, `report.build_config`)은 건드리지 않는다. 기존 `config_hash`가 그대로 유지돼야 한다.
- 이 연구의 신규 시도는 기존 54개에 누적한다.

## 1. 검증 구간 (사용자 결정: 전진 검증)

- 이전 ETF 연구는 2008-12-22~2026-11-20을 fold test와 holdout으로 이미 썼다. 실제 값은 `research-data/full-report.json`에 있다.
- **과거 데이터 전체(~2026-11-20)는 탐색·개발 용도로만 쓴다.** 과거 결과로 내릴 수 있는 최선의 판정은 "전진 확증 후보"다.
- **확증 구간**은 등록 커밋 다음 거래일(2026-11-24)부터 최소 252거래일이다. 모의운용 기록이며 실주문은 없다.

## 2. 가설

- H1 (M1 > M0): 같은 섹터 선도 종목의 전일 수익률은, 시장·섹터·자기 전일 수익률(M0)이 이미 담은 정보 외에 후행 종목의 다음 날 수익률 예측력을 추가로 가진다.
- 선행 연구: Lo-MacKinlay 1990, Hou 2007(산업 내 대형주가 소형주를 선행함), Cohen-Frazzini 2008(고객-공급사 관계, M2 영역).
- 사전 예상: 대형주끼리, 일봉, 2000년대 이후 표본에서는 효과가 약하거나 비용을 넘지 못할 가능성이 높다. 무효(null) 결과도 정상 결과로 보고한다.

## 3. 데이터

### 3.1 가격

- 기존 수집기 `scripts/collect-toss-candles.py`를 쓴다. 조건: 1d, count=200, nextBefore, adjusted/unadjusted 둘 다.
- 고정 종목 43개. 오늘 판단으로 고른 고정 목록이며 이 커밋으로 동결한다.
- 기준: 섹터별로 2000년 이전부터 상장된 대표 대형주 5개.

| 섹터 ETF | 종목 |
|---|---|
| XLK | AAPL, MSFT, NVDA, ORCL, CSCO |
| XLF | JPM, BAC, WFC, C, GS |
| XLE | XOM, CVX, COP, SLB, OXY |
| XLV | JNJ, PFE, MRK, ABT, AMGN |
| XLP | PG, KO, PEP, WMT, CL |
| XLI | CAT, GE, HON, BA, DE |
| XLY | AMZN, HD, MCD, NKE, LOW |

- 시장 요인은 SPY(기존 수집분 재수집)로 한다.
- 데이터 무결성 검사는 기존 수집기와 로더 검사를 그대로 적용한다: 중복, 갭, 페이지 경계, OHLC 비율, 미완성 일봉 제외.

### 3.2 배당 (사용자 승인: 무료 외부 소스)

- 출처: Yahoo Finance chart API의 `events=div` 공개 엔드포인트. API 키 없음, 비용 0, 읽기 전용 GET.
- 금액은 Toss 분할조정 가격 기준과 맞는지 검증한 뒤 쓴다. 검증 규칙은 데이터를 보기 전에 다음과 같이 고정한다.
  - 배당락일이 모두 Toss 거래일에 매핑된다.
  - 이벤트별 수익률 D / C(t-1, 분할조정)는 0 초과 15% 이하다.
  - Toss의 unadjusted/adjusted 비율에서 분할 일자를 찾는다. 각 분할일 전후 252일의 배당수익률 합계 비율이 [0.5, 2] 범위에 있다(분할 기준 불일치 탐지).
- 통과한 종목만 배당 역조정 가격을 만든다. 방식: 배당락 이전 모든 OHLC에 (1 − D/C(ex−1))을 곱한다.
- 통과한 종목은 `SPLIT_AND_DIVIDEND`(파생)으로 표시한다. 하나라도 실패하면 그 종목은 판정 데이터셋에서 제외하고 보고한다. 데이터를 대체하거나 보정하지 않는다.

### 3.3 편향

- 생존 편향: **제한적이며 통제하지 못한다.** 오늘 상장된 대형주만 존재한다. 이 편향은 롱온리 결과를 위로 민다. 따라서 무효 결과가 유효 결과보다 신뢰도가 높다.
- 미래 정보: 결정은 t 종가 기준이고 체결은 t+1 시가다. 회귀 계수는 학습 구간 데이터로만 적합한다. 선도주 선정은 t 이전 데이터만 쓴다.
- 체결 가능성: Toss 개인 계좌는 미국 주식 공매도가 불가하므로 **롱온리만 판정 대상**이다(엔진도 가중치 [0,1], 합 ≤ 1). 비중은 소수 단위로 가정한다.

## 4. 모델 (고정, 추가 탐색 금지)

### 4.1 수익률 정의

- r(t)는 t의 종가 대비 수익률이다.
- 예측 목표(주 목표, 거래 가능 수익률)는 open(t+1) → open(t+2)다. 엔진의 1일 보유 수익률과 같다.

### 4.2 모델 정의

- M0: y_i = a + b1·r_SPY(t) + b2·r_sector(t) + b3·r_i(t)
- M1: M0 + c·r_leader(s,t)
- 선도주 leader(s,t)는 섹터 s에서 t까지 63일 평균 거래대금(종가×거래량)이 가장 큰 종목이다. 시점 기준으로 정한다.
- 선도주 자신의 M1 예측은 M0와 같다.
- 종목 쌍 자유 탐색(N² 쌍)은 금지한다.
- 적합: 종목별 OLS, 학습 756거래일. 기존 엔진과 같이 252일마다 재적합하는 walk-forward로 학습 756, 시험 252, 이동 252다.
- 종목별 학습·시험 구간에 데이터가 모두 있는 종목만 그 fold의 유니버스로 쓴다. 전역 교집합 정렬은 하지 않는다.

### 4.3 포트폴리오

- 매일 t 종가에 예측 ŷ를 산출한다. ŷ > 0.30%(왕복 비용)인 종목 중 상위 k개를 각 1/k 비중으로 담고, 나머지는 현금이다.
- 체결은 t+1 시가다.
- 비용: 수수료 10bp + 슬리피지 5bp(편도). 2배 비용 스트레스 테스트를 함께 본다.

### 4.4 시도 수

- 모델 {M0, M1} × k {3, 5} = 4개. 누적 N = 54 + 4 = **58**.
- DSR의 Sharpe 분산은 max(신규 4개 연구구간 Sharpe 분산, 기존 54개 분산)이다. 보수적으로 잡는다.

## 5. 판정 규칙 (과거 탐색 구간, walk-forward 이어붙인 OOS)

### G1: M1이 M0보다 유의하게 나은가

단측 α = 0.05. 두 조건을 모두 충족해야 한다.

- T1: Clark-West 검정. M0이 M1에 포함된 모형이므로 이 검정을 쓴다. 주 목표의 OOS 예측을 쓰고, 일별 종목 평균 CW 통계량을 Newey-West(lag 5)로 검정한다.
- T2: (M1, k=5) − (M0, k=5) 일별 순수익률 차이의 평균 > 0. Newey-West(lag 5)로 검정한다.

### G2: 모의운용 후보 자격

M1 (k=5 주, k=3 보조) 기준으로 기존 엔진 기준을 그대로 쓰되, holdout 대신 전진 구간을 쓴다.

- DSR ≥ 0.95 (N = 58)
- OOS Sharpe > SPY OOS Sharpe
- active PSR ≥ 0.95
- 2배 비용 OOS Sharpe > 0
- adjustment_basis = SPLIT_AND_DIVIDEND

### 진단 (판정에 쓰지 않음, 사전 분류)

- 신호 품질과 체결 가능 수익률을 나눠 기록한다. 같은 예측으로 close(t)→close(t+1), 밤사이 갭 close(t)→open(t+1), 장중 open(t+1)→close(t+1)에 대해 CW를 각각 계산한다.
- 결과 분류
  - "신호 있음·체결 불가": close→close CW는 유의하지만 주 목표 CW는 유의하지 않은 경우
  - "신호 있음·비용 미달": 주 목표 CW는 유의하지만 T2가 실패한 경우

## 6. 중단 규칙과 M2/M3 판단

- **G1 실패**: M1 개선 없음. 연구를 중단한다. M2(경제적 관계)와 M3(공시·뉴스)는 구현하지 않는다.
- **G1 통과, G2 실패**: 원인을 분류한다.
  - 비용·체결 문제이면 M2/M3도 같은 체결 제약을 받으므로 확장을 권하지 않는다.
  - 신호 강도 문제이면 M2(고객-공급사 데이터, 무료 소스 확보 가능성 먼저 확인)만 별도 등록(LL-2)으로 제안한다.
- **G1·G2 통과**: 전진 확증 후보로 등록하고 모의운용(기록만)을 한다. M2/M3는 전진 결과 이후에 판단한다.

## 7. 전진 확증 기준 (2026-11-24 이후, 최소 252거래일)

- 같은 코드와 같은 고정 설정(재적합 일정 포함)을 쓴다.
- 통과 조건
  - 순 Sharpe의 PSR(vs 0) ≥ 0.90
  - M1 − M0 일별 순수익률 차이 평균 > 0
  - 실제 데이터 기준 SPLIT_AND_DIVIDEND 유지
- 전진 기간 통과 전에는 어떤 실주문 연결도 하지 않는다.

## 부록 A. 개정 (2026-11-23, 결과 확인 전)

- **개정 내용**: §3.1의 무결성 검사에서 Toss 수집의 `stop_reason = MAX_PAGES`(페이지 상한 도달)를, 두 시계열(조정·미조정) 모두의 첫 봉 날짜가 분석 시작일 1998-12-22 이전이거나 같을 때에 한해 허용한다. `NO_PROGRESS`는 항상 실패다. 허용된 종목은 검사 결과 `TRUNCATED_BEFORE_ANALYSIS_START`와 두 시계열의 첫 날짜를 매니페스트에 기록한다. 분석 시작일 이후에 시작하는 `MAX_PAGES`는 여전히 실패한다. 분석 시작일은 `total_return` CLI의 `--analysis-start`로 지정하며 기본값은 1998-12-22다.
- **개정 사유**: `MAX_PAGES` 절단은 가장 오래된 이력만 잘라낸다. 분석은 폴드가 섹터 ETF 첫 완전 봉(1998-12-22) 이후에서 시작하므로 잘린 구간을 쓰지 않는다. 기본 수집 페이지 상한(40페이지, 8000봉)에서는 1995년부터 시작하는 대형주가 모두 이 사유로 제외되는데, 이는 검증 대상 구간의 무결성 문제가 아니다.
- **시점**: 이 개정은 LL-1 판정 결과가 생성되기 전에 이루어졌다. 리드-래그 판정 보고서는 생성된 적이 없고 판정 실행도 없다.
- **원 등록과의 관계**: 원 등록(84fe065) §3.1은 "기존 수집기와 로더 검사를 그대로 적용한다"고 적었다. 이 부록은 그 문장에 대한 명시적 예외다. 원 커밋은 수정하지 않으며, 이 개정은 별도 커밋으로 기록된다.
- **범위**: 판정 규칙(G1, G2, 임계값, 비용, 검정 방법)과 분석 구간은 바꾸지 않는다. 배당 검증 규칙(§3.2)은 그대로 적용된다.
- **검토 사항**: §0은 판정 규칙을 바꾸면 LL-2로 취급하도록 한다. 이 예외는 데이터 무결성 검사에 해당하며 판정 규칙이 아니라고 보았다. 다만 보수적으로는 LL-2로 등록하는 것이 맞을 수 있으며, 이 해석은 검토자가 결정한다.
