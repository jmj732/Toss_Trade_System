# MODE 9 — PORTFOLIO REVIEW

> DRAFT ONLY: local copy for review; synced ChatGPT project source and scheduled tasks remain unchanged.

## 목적

사용자의 전체 포트폴리오를 현재 시점에서 재평가하고, 각 포지션과 전체 구조를 어떻게 조정해야 하는지 결정한다.

핵심 질문:

> 지금 이 포트폴리오를 처음부터 다시 구성한다면 현재와 같은 종목·비중을 선택할 것인가?

단순 수익률 보고서가 아니다.
보유 이유, 기대수익, 하방 위험, 집중도, 상관관계, 기회비용을 함께 평가하여 실제 행동 우선순위를 만든다.

## 0. Portfolio Input Validation
분석 시작 전에 입력 비중 합계가 100%인지 검증한다.

- 합계 = 100% → 그대로 진행
- 합계 < 100% → 차이를 `Unknown Exposure`로 표시
- 합계 > 100% → 입력 오류 가능성을 명시하고 중복·레버리지 여부를 확인

`Unknown Exposure`의 종목·섹터·상관관계·위험을 임의 추정하지 않는다. 전체 위험·집중도·현금 판단에는 이 데이터 한계를 명시한다.

## 입력

가능하면 다음을 사용한다.

- 총 투자자산
- 현금
- 각 보유 종목의 티커
- 수량
- 평균 매수가
- 현재 비중
- 투자기간
- 추가 투자 가능 금액
- 최대 허용 손실
- 매도 제한 또는 세금 고려사항
- 사용자가 가진 투자 Thesis

일부 정보가 없으면 확인 가능한 부분부터 분석하고, 없는 정보 때문에 계산할 수 없는 항목을 명시한다.

## 1. 최신 포트폴리오 스냅샷

각 보유 종목의 최신 데이터를 확인한다.

가능한 범위에서:
- 현재가
- 당일 변동
- 5일 / 20일 / 60일 수익률
- 20/50/200DMA 위치
- 최근 실적
- 가이던스
- EPS / Revenue Revision 방향
- 다음 주요 Catalyst

포트폴리오 전체:
- 총 평가금액
- 현금 비중
- 종목별 비중
- 섹터별 비중
- 테마별 비중
- 대형/중형/소형주 비중
- 성장/가치 성향
- 고베타/저베타 노출
을 계산 가능한 범위에서 정리한다.

## 2. Market Regime 적합성

현재 시장 Regime을 간단히 판정한다.

그 다음 포트폴리오가 현재 환경에 적합한지 본다.

예:
- 금리 상승에 지나치게 민감한가?
- AI/반도체 한 테마에 과도하게 집중됐는가?
- Risk-off인데 고베타 소형주 비중이 과도한가?
- Risk-on인데 현금이 과도하여 기회비용이 큰가?

판정:
- 매우 적합
- 적합
- 중립
- 부적합
- 매우 부적합

## 3. 각 보유 종목 Thesis Health

각 종목을 다음 기준으로 재평가한다.

- 사업의 질
- 성장의 질
- 최근 실적
- 가이던스
- Earnings Revision
- Expectations Gap
- 밸류에이션
- 가격/상대강도
- Catalyst
- 핵심 리스크

각 종목의 투자 Thesis를 다음 중 하나로 판정한다.

- 강화됨
- 유지됨
- 약화됨
- 훼손됨

평단과 손익률 때문에 Thesis 판정을 바꾸지 않는다.

### 투자기간별 검토 창

각 보유 종목은 Thesis classification과 별도로 Spring `positionMandates`의 저장 기간과 위험가격 역할을 읽는다. 누락 시에는 공통 Portfolio Manager의 여섯 사용자 확정 매핑만 fallback으로 사용하고 다른 종목은 `UNKNOWN`으로 둔다.

- TACTICAL (CSTM, AVT): 20~60거래일 결과를 기준으로 추세, 거래량, 모멘텀, 상대강도와 실적을 평가한다. 단기 매매 성과와 장기 기업 전망을 섞지 않는다.
- STRATEGIC (LUNR, VST, GOOGL, RDW): 6~18개월 기대수익과 사업 Thesis를 평가한다. 가격 위험은 재검증 신호로 기록하고, 사업·실적·Revision·유동성·Thesis Health를 반영한다. Thesis 유지 시 HOLD 가능하며 이 기간은 강제 매도 시한이 아니다.
- Hard Risk Gate와 구조적 Thesis 훼손은 투자기간과 독립해 다룬다. 가격 위험, Thesis Health, 포트폴리오 행동은 서로 다른 필드로 기록한다.
- 종목별 Action Table에 `investmentHorizon`, `priceRiskState`, `thesisHealth`, `actionReason`을 추가한다. 축소·매도에는 매도 수량과 근거를 기록하고, 호가·계좌·승인 검증 없이는 주문 준비/제출로 이어가지 않는다.

## 4. Forward Expected Return

각 종목은 과거 수익률이 아니라 현재 가격 기준으로 평가한다.

가능하면 각 종목에 대해:
- Bull upside
- Base upside/downside
- Bear downside
- 예상 보유기간
- 기대수익의 핵심 촉매
- 무효화 조건
을 제시한다.

정밀한 확률을 가장하지 않는다.
필요하면 확률 범위와 불확실성을 사용한다.

## 5. Concentration Risk

다음 집중 위험을 확인한다.

- 단일 종목
- 단일 섹터
- 단일 테마
- 동일한 매크로 요인
- 동일한 고객/산업 사이클
- 동일한 AI/반도체 Capex 사이클
- 동일한 금리 민감도

서로 다른 티커라도 실제 위험요인이 같으면 분산으로 간주하지 않는다.

## 6. Correlation / Hidden Exposure

가능한 범위에서 실제 가격 상관관계와 경제적 상관관계를 본다.

특히:
- 여러 종목이 Nasdaq/SOX 하나에 사실상 같은 베팅인지
- 대형 기술주 여러 개가 동일한 AI Capex 내러티브에 의존하는지
- 방산 종목 여러 개가 같은 지정학 Catalyst에 의존하는지
- ETF와 개별주가 중복 노출되는지
확인한다.

## 7. Catalyst Calendar

향후 20거래일 및 사용자의 투자기간 안에서 포트폴리오 전체의 주요 이벤트를 정리한다.

예:
- 실적
- CPI/PCE/고용/FOMC
- Investor Day
- 제품 발표
- 규제 결정
- 임상/허가
- 주요 계약

같은 시기에 여러 위험 이벤트가 겹치는지 확인한다.

## 8. Downside Stress Test

최소 다음 시나리오를 생각한다.

### Scenario A — 일반 조정
주요 지수 약 -5% 수준의 위험회피.

### Scenario B — 성장주 충격
Nasdaq/SOX 및 고밸류 성장주의 급격한 멀티플 축소.

### Scenario C — 종목 고유 악재
가장 큰 비중 종목의 Thesis 훼손.

각 시나리오에서 어떤 포지션이 가장 큰 손실 기여자가 될지 판단한다.
정밀 계산이 불가능하면 방향성과 상대적 취약도를 표시한다.

## 9. Opportunity Cost

현재 보유 종목 각각에 대해 묻는다.

> 이 종목을 오늘 보유하지 않았다면 현재 가격에 새로 살 것인가?

답이 아니오라면 단순히 손실 중이라는 이유로 계속 보유하지 않는다.

현금 및 MODE 8의 신규 후보와 비교해 자본의 기회비용을 평가한다.

## 9A. Standalone vs Portfolio Decision
개별 종목의 standalone 판단과 Portfolio Action은 달라질 수 있다.

예:
- standalone으로는 `보유 가능`
- 포트폴리오에서는 집중도·상관관계·현금 부족·기회비용 때문에 `축소`

두 판단이 다르면 오류로 보지 말고 반드시 차이의 원인을 설명한다:
`집중도 / 상관관계 / 현금 / 기회비용 / 이벤트 중첩 / 전체 Downside 기여`.

## 10. 종목별 Action

각 종목에 반드시 하나를 부여한다.

1. 적극 확대
2. 소폭 확대
3. 유지
4. 일부 축소
5. 대폭 축소
6. 전량 매도

각 판단에 대해:
- 이유
- 목표 비중
- 최대 비중
- 실행 조건
- 무효 조건
을 제시한다.

## 11. Portfolio Rebalance

전체 포트폴리오 기준으로 제안한다.

- 줄일 종목
- 늘릴 종목
- 신규 편입 후보 필요 여부
- 현금 목표
- 섹터/테마 목표
- 실행 우선순위

한 번에 불필요하게 모든 포지션을 바꾸지 않는다.
기대값 개선이 명확한 조정만 제안한다.
